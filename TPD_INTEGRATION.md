# Travel Partner Directory (TPD) Integration

This branch (`feat/tpd-integration`) adds the SSO handoff, server-to-server bridge API, and iframe embedding headers needed to connect the WordPress **Travel Partner Directory (`tpd-tool`)** portal with this LMS.

---

## 1. Production `.env` Variables

Add these variables to the LMS `.env` file (and mirror `TPD_SSO_SECRET` / `TPD_API_TOKEN` inside WordPress Super Admin → LMS settings):

```dotenv
TPD_SSO_SECRET=replace-with-64-char-random-secret
TPD_API_TOKEN=replace-with-64-char-random-token
TPD_SSO_TTL=120
TPD_BASE_URL=https://tpd.tarctpc.com
TPD_FRAME_ANCESTORS="'self' https://tpd.tarctpc.com"

# Optional outbound webhook (LMS -> WordPress)
TPD_WEBHOOK_URL=https://tpd.tarctpc.com/wp-json/tpd/v1/lms-webhook
TPD_WEBHOOK_SECRET=replace-with-webhook-secret
```

### Changing Domains Before Launch
If the WordPress or LMS domain changes later while staying on the same server, update:
1. `APP_URL` on Laravel `.env`
2. `TPD_BASE_URL` and `TPD_FRAME_ANCESTORS` on Laravel `.env`
3. If WordPress and the LMS ever move to **different registrable root domains** (not subdomains of the same domain), also set:
   ```dotenv
   SESSION_SAME_SITE=none
   SESSION_SECURE_COOKIE=true
   SESSION_PARTITIONED_COOKIE=true
   ```
   so the `/studio` and `/admin` iframe cookies remain valid inside cross-site frames.

## 2. Signed SSO Endpoint (`GET /sso/login`)

Query parameters generated by WordPress backend:
- `token`: Base64URL-encoded JSON payload:
  ```json
  {
    "tpd_user_id": 42,
    "email": "advisor@example.com",
    "name": "Jane Advisor",
    "role": "travel_advisor",
    "redirect": "/dashboard",
    "iat": 1762950000,
    "exp": 1762950120,
    "nonce": "random-string-at-least-16-chars"
  }
  ```
- `sig`: `hash_hmac('sha256', $token, $ssoSecret)` (64-char lowercase hex).

### Role Mapping & Safety
- `administrator` / `super_admin` → `super_admin`
- `admin` → `admin`
- `instructor` → `instructor`
- `travel_advisor` / `advisor` / `pro` / `supplier` / `student` → `student`
- Existing privileged LMS users (`instructor`, `admin`, `super_admin`) are never downgraded when opening a student course link.
- Tokens are verified with HMAC-SHA256, bounded by `exp`/`iat`, single-use via atomic cache nonce consumption, and sanitize `redirect` to relative paths only.

## 3. Authenticated Bridge API (`/api/tpd/*`)

Authenticate requests with `Authorization: Bearer <TPD_API_TOKEN>` (or `X-TPD-Token`):

| Method | Path | Purpose |
| --- | --- | --- |
| `GET` | `/api/tpd/health` | Connectivity check + currency |
| `GET` | `/api/tpd/catalog` | Published courses (`?status=all` & `?q=` supported) |
| `GET` | `/api/tpd/enrollments` | User's enrolled courses, progress %, certificates & orders (`?tpd_user_id=` / `?email=`) |
| `POST` | `/api/tpd/enroll` | Idempotent order + enrollment creation keyed by `external_reference` |
| `GET` | `/api/tpd/admin/overview` | Studio/Admin stats, monthly revenue, all courses, recent 20 orders |
| `POST` | `/api/tpd/courses/{course:slug}/publish` | Toggle course `published` ↔ `draft` |

---

## 4. Iframe Embedding Headers

Middleware `tpd.frame` (`AllowTpdFrameAncestors`) removes `X-Frame-Options` and emits `Content-Security-Policy: frame-ancestors ...` from `TPD_FRAME_ANCESTORS` on:
- `/sso/login`
- `/studio/*`
- `/admin/*`
- `/courses/{course}`
